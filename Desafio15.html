O objetivo deste projeto é realizar um teste de capacidade de processamento da linguagem de programação Julia. Para isso, utilizamos loops seriais e loops paralelos em dois exemplos, e medimos o tempo gasto para processá-los. Além disso, foi feito um comparativo com as linguagens de programação R e Python no segundo exemplo, a fim de ter uma melhor referenciação.

O exemplo 1 apresenta um problema simples de subtração de um somatório pequeno por outro consideravelmente maior. Neste caso, o loop serial apresentou um desempenho superior ao loop paralelo. Isso ocorre porque o trabalho realizado em cada iteração é bastante simples (apenas um teste condicional e uma soma), tornando o custo de paralelização muito maior do que o ganho potencial.

(R)

library(parallel)

serial_R <- function(n) {
  s <- 0
  for (i in 1:n) {
    s <- s + sin(i) * cos(i/2)
  }
  s
}

parallel_R <- function(n) {

  cores <- max(1, detectCores() - 1)
  cl <- makeCluster(cores)
  on.exit(stopCluster(cl))

  clusterExport(cl, varlist = c("sin", "cos"), envir = environment())

  result <- parLapply(cl, 1:n, function(i) sin(i) * cos(i/2))

  sum(unlist(result))
}

run_example <- function(n) {
  t1 <- Sys.time()
  r1 <- serial_R(n)
  t2 <- Sys.time() - t1

  t3 <- Sys.time()
  r2 <- parallel_R(n)
  t4 <- Sys.time() - t3

  list(
    serial_result = r1,
    serial_time = t2,
    parallel_result = r2,
    parallel_time = t4
  )
}

run_R <- run_example(2000000)

import time
import random
import math
from concurrent.futures import ThreadPoolExecutor

def compute_value(x):
    if x < 0.33:
        return math.sin(x)
    elif x < 0.66:
        return math.log1p(x)
    else:
        return math.sqrt(x)

def run_serial(n_iter):
    start = time.time()
    acc = 0.0

    for _ in range(n_iter):
        x = random.random()
        acc += compute_value(x)

    end = time.time()
    return {"resultado": acc, "tempo": end - start}

def run_parallel(n_iter):
    start = time.time()

    xs = [random.random() for _ in range(n_iter)]

    with ThreadPoolExecutor(max_workers=8) as executor:
        resultados = list(executor.map(compute_value, xs))

    acc = sum(resultados)

    end = time.time()
    return {"resultado": acc, "tempo": end - start}

N = 2_000_000

serial = run_serial(N)
parallel = run_parallel(N)

print("\n" + "="*60)

Este exemplo utilizou de um problema um pouco mais complexo com 2 milhões de iterações envolvendo operações matemáticas mais custosas (seno, log e raiz quadrada). Novamente, o loop serial se sobressaiu ao loop paralelo. Por outro lado, a liguagem Julia demonstrou desempenho amplamente superior as duas outras linguagens. Seu tempo de processamento foi 10 vezes mais rápido que ambas, nos dois tipos de loop (100 vezes mais rápido no caso do loop paralelo do Python, porém, mais por conta de uma limitação do software utilizado para executar os códigos que nos obrigou a utilizar um método não convencional para o este tipo de loop).

Conclusão: Julia é uma linguagem de programação mais moderna e mais capacitada para o alto desempenho exigido atualmente. Essa afirmação se justifica no comparativo com o R e o Python, onde ela teve velocidade de processamento amplamente maior. Por outro lado, a vantagem do loop serial sobre o loop paralelo em ambos os casos pode ter um caráter enviesado. Análises utilizando problemas ainda mais complexos e exigentes podem fornecer um cenário onde a paralelização do loop obtenha desempenho superior ao loop em série comum.
